# Python Data Analytics Assignment 1: NumPy and Pandas

## 📌 Project Overview

This repository contains my first Python Data Analytics assignment, focusing on **NumPy and Pandas** for numerical computations and data manipulation.

The assignment demonstrates fundamental data analysis operations using temperature data, student marks, and transaction records.

## 🎯 Objectives

- Learn to create and manipulate NumPy arrays.
- Perform numerical calculations and array slicing.
- Understand Pandas Series, indexing, and filtering.
- Create and explore Pandas DataFrames.
- Apply conditional filtering, grouping, and aggregation.
- Modify and delete rows and columns.

## 🛠️ Technologies Used

- **Python**
- **NumPy** – Numerical computing and array operations.
- **Pandas** – Data manipulation and analysis.
- **Jupyter Notebook** – Interactive coding and documentation.

## 📚 Topics Covered

### 1. NumPy Array Operations
- Creating 1D and 2D arrays.
- Inspecting array shape, data type, and size.
- Converting temperatures from Celsius to Fahrenheit.
- Calculating maximum, minimum, and mean temperatures.
- Array indexing and slicing.

### 2. Pandas Series
- Creating a Series with custom indices.
- Accessing values using `loc` and `iloc`.
- Boolean masking and filtering.
- Updating and removing Series elements.
- Performing calculations on Series values.

### 3. Pandas DataFrame
- Creating a transaction dataset.
- Exploring data using `head()`, `tail()`, `shape`, `columns`, `dtypes`, and `info()`.
- Selecting specific columns and filtering rows.
- Counting categories and finding unique values.
- Grouping data by region and calculating mean transaction amounts.
- Updating transaction values and adding or deleting columns.
- Removing rows based on conditions.

## 📂 Repository Contents

- `Python_Data_Analysis_np_pd.ipynb` – Jupyter Notebook containing the assignment code and outputs.
- `README.md` – Project overview, objectives, and topics covered.

## 🚀 How to Run

1. Clone or download this repository.
2. Install Python if it is not already installed.
3. Install the required libraries:

   ```bash
   pip install numpy pandas notebook
   ```

4. Navigate to the project folder.
5. Start Jupyter Notebook:

   ```bash
   jupyter notebook
   ```

6. Open `Python_DA_Assignment_1_NumPy_Pandas.ipynb`.
7. Run the notebook cells in order.

Alternatively, open the notebook in Google Colab.
